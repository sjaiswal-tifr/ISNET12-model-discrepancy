# ISNET-12 BAND Camp: Discrepancy functions and using them in calibrationThis repository contains the tutorial materials for the [**ISNET-12 BAND Camp**](https://conferences.lbl.gov/event/2526/page/332-band-camp-monday-october-5) on incorporating model discrepancy in Bayesian calibration.The tutorial introduces the idea of treating model discrepancy as an unknown function, assigning it a functional prior using a Gaussian process, and inferring the discrepancy simultaneously with the physical model parameters.## Tutorial websiteThe rendered Jupyter Book is available at:[**Jupyter Book**](https://sjaiswal-tifr.github.io/ISNET12-model-discrepancy/) ## Interactive notebook *Demo: Ball-drop experiment*A simplified ball-drop demonstration can be run directly in Google Colab:**[Run in Google Colab](https://colab.research.google.com/github/sjaiswal-tifr/ISNET12-model-discrepancy/blob/main/content/demo-ball-drop-experiment_v2.ipynb)**## Contents* Introduction to Bayesian calibration and model discrepancy* Functional priors for discrepancy functions* Gaussian-process covariance kernels and their hyperparameters* Ball-drop example illustrating the effect of model discrepancy on parameter inference* Application of model discrepancy framework to heavy-ion problems ## Model discrepancy repositoryThe main repository of the model-discrepancy framework is available
